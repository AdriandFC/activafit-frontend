# ActivaFit · Front-End (v1)
Panel web para que un gimnasio vea qué socios tienen riesgo de abandono. Parte del proyecto de ML "ActivaFit" (regresión logística sobre Sport Services Dataset).

- **Vistas:** Panel, Socios (buscador + filtro + marcar contactado), Evaluar socio (formulario validado).
- **Datos:** `data/socios.json` (ficticios) y `data/modelo.json` (coeficientes **provisionales**; reemplazar con los del Colab).
- **Ejecutar:** `npx serve .` o Live Server (fetch no funciona con `file://`).
- **Publicar:** GitHub Pages → Settings → Pages → rama `main`, carpeta `/root`.
